# منظومة الهويات والمستمسكات IQ

## التشغيل على ويندوز (بايثون 3.10+)
1. ثبّت Python من python.org (فعّل خيار Add Python to PATH).
2. انقر مرتين على `run.bat`.

## إنشاء ملف EXE
انقر مرتين على `build_exe.bat` ← يظهر الملف في `dist\IQ_Studio.exe`.

## الاستخدام
- إضافة مستمسك ← رفع الوجه/الظهر ← ضبط العرض والارتفاع بالسنتيمتر.
- اسحب البطاقة في المعاينة لنقلها (يمنع التداخل)، أو اضغط «ترتيب تلقائي».
- تحرير الوجه/الظهر: قص بالسحب، تدوير، ميلان، سطوع، تباين، أبيض وأسود، تحسين.
- ملف ← حفظ: ملف .iqproj يحوي الصور نفسها.
- الطباعة: تُرسل A4 كاملة بنسبة 100%؛ تأكد من اختيار "الحجم الفعلي" في إعدادات الطابعة.
- الروابط والاسم والأبعاد الافتراضية من: ملف ← الإعدادات.
